## Student Management System

My first Java OOP project a console-based Student Management System built while learning Java and Object-Oriented Programming.

**_ Features _**

- Add a student
- Display the number of students
- Student login and logout
- Check login status
- Search for a student by name
- Get a student's average
- Change a student's password
- Automatically generate student IDs

**_ Technologies _**

- Java
- Object-Oriented Programming
- Git
- GitHub

**_ Concepts Practiced _**

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Getters and Setters
- Static variables and methods
- Arrays
- Loops and Conditions
- User Input with `Scanner`

**_ How to Run _**

1. Clone the repository.
2. Open the project in your Java IDE.
3. Compile the Java files.
4. Run `Main.java`.
